# Starter

The starter contains the exercise setup. Add the provided Java server and static frontend used by your instructor, or connect the frontend to your own day 4 API.

Run the frontend from this directory with a local server such as:

```bash
python3 -m http.server 5500
```

The API should run on port 8080. Compare browser behavior with:

```bash
curl -i http://localhost:8080/profile
```
